# Galeri Vertikal

Aplikasi Android sederhana untuk memilih banyak foto dan melihatnya sebagai satu guliran vertikal.

## Fitur versi 1.0

- Menampilkan foto perangkat dalam galeri tiga kolom
- Memilih banyak foto sesuai urutan ketukan
- Mengatur ulang dengan tarik dan lepas
- Membaca gambar berurutan dengan gulir atas–bawah
- Jarak antargambar rapat, tipis, atau lebar
- Mode layar penuh
- Pemilih dokumen sebagai cadangan jika izin galeri tidak diberikan
- Tidak mengunggah atau mengirim foto ke internet

APK debug dibuat otomatis melalui GitHub Actions.
